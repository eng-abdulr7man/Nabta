# 🌱 Nabta Platform

Nabta is a modern educational platform focused on agricultural and biological sciences, designed to provide structured courses, clean UI, and a smooth learning experience.

🔗 Live Demo: https://nabta.vercel.app  
📂 GitHub Repo: https://github.com/eng-abdulr7man/Nabta

--- 

## 🚀 Features

- 🎓 **Structured Learning Experience**  
  Well-organized courses in Biology, Agriculture, and Veterinary sciences with a clear and progressive learning path.

- 📱 **Fully Responsive Design**  
  Optimized for all screen sizes, ensuring a seamless experience across mobile, tablet, and desktop devices.

- 🌙 **Modern Dark UI**  
  Clean and elegant dark interface designed for better focus and visual comfort.

- ⚡ **High Performance**  
  Powered by Vite and deployed on Vercel for fast load times and smooth user interactions.

- 🧭 **Seamless Navigation & UX**  
  Intuitive routing and user-friendly design for effortless navigation.

- 🛒 **Content & Product Showcase**  
  Flexible system for presenting educational content and products in a clean and engaging way.

- 🧩 **Scalable Architecture**  
  Component-based structure using React for easy maintenance and future scalability.

- 🔗 **Backend Integration Ready**  
  Built to integrate بسهولة with Supabase for authentication and database management.

- Supabase (Auth & Database)

## ⚙️ Installation

```bash

cd Nabta
npm install
npm run dev
```
