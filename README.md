# 🌱 Nabta Platform

Nabta is a modern educational platform focused on agricultural and biological sciences, designed to provide structured courses, clean UI, and a smooth learning experience.

🔗 Live Demo: https://nabta.vercel.app  
📂 GitHub Repo: https://github.com/eng-abdulr7man/Nabta

---

## 🚀 Features

- 🎓 Structured Courses (Biology, Agriculture, Veterinary)
- 📱 Fully Responsive Design
- 🌙 Modern Dark UI
- ⚡ Fast Performance (Vercel Deployment)
- 🧭 Smooth Navigation & UX
- 🛒 Product & Educational Content Showcase
- 📂 Organized Components Architecture

---

## 🧱 Tech Stack

### Frontend
- React.js
- Tailwind CSS
- React Router

### Backend (if applicable)

```bash

cd Nabta
npm install
npm run dev
```
